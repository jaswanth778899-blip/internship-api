# Submission Checklist

## Required

- [x] Node.js project
- [x] Express server
- [x] Internship data model
- [x] SQLite persistence
- [x] Schema included
- [x] Seed data included
- [x] GET list endpoint
- [x] GET detail endpoint
- [x] POST create endpoint
- [x] PUT full update endpoint
- [x] PATCH partial update endpoint
- [x] DELETE endpoint
- [x] Input validation
- [x] Consistent success responses
- [x] Consistent error responses
- [x] Pagination
- [x] README setup instructions
- [x] API examples

## Before Submitting

- [ ] Run `npm install`
- [ ] Run `npm start`
- [ ] Open `http://localhost:3000`
- [ ] Open `http://localhost:3000/api/internships`
- [ ] Test POST request
- [ ] Test PUT or PATCH request
- [ ] Test DELETE request
- [ ] Push the folder to a public GitHub repository
- [ ] Submit the GitHub repository URL as the one proof link
